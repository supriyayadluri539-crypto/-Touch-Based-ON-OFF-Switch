# 🔘 Touch-Based ON/OFF Switch

A touch-controlled electronic switching project built using a **TTP223 Touch Sensor Module, LED, resistor, and 3.7 V rechargeable battery**. The project demonstrates the practical implementation of touch sensing and electronic switching on a PCB.

---

## 📌 Project Overview

The Touch-Based ON/OFF Switch provides a simple and convenient way to control an LED through touch.

The **TTP223 touch sensor module** detects the touch input and provides a digital output signal. This signal is used to control the LED through the connected circuit. A **3.7 V rechargeable battery** is used as the power source.

The project helped in gaining practical experience in **electronic circuit design, touch sensing, PCB implementation, hardware assembly, testing, and troubleshooting**.

---

## 🎯 Project Objective

The main objectives of this project are:

- To understand the working of a touch sensor.
- To design a simple touch-controlled electronic circuit.
- To implement the circuit on a PCB.
- To test the circuit through a prototype setup.
- To demonstrate ON/OFF control using touch input.

## ⚙️ Working Principle

1. The **3.7 V rechargeable battery** supplies power to the circuit.
2. The **TTP223 touch sensor** detects the touch input.
3. When the touch sensor is activated, its digital output changes.
4. The output signal is used to control the LED through the connected circuit.
5. The resistor limits the current flowing through the LED.
6. The LED provides a visual indication of the switching state.
